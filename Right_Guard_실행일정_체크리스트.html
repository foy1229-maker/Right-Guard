★지금까지 완료한 것 진행일지(2) · 10월 1주까지
레이더 + ESP32 2대 + P10 LED로, 노트북 없이 혼자 동작하는 장치 완성

사람이 감지되면 LED가 ✕, 사라지고 1초 뒤 →로 바뀌는 데까지 확인했어요.

  1. ✓8월 1~2주 · 기존 프로토타입(라즈베리 파이·초음파·소형 LED·유선)에서 개선 방향 확정 — MCU를 ESP32 2대 + 블루투스로, 운전자용 LED와 사람만 감지하는 레이더 센서(LD2410) 구매 (중간발표 피드백: 뛰어오는 아이까지)
  2. ✓8월 3주 · LD2410 동작 확인(라즈베리 파이) 후 ESP32 연결 — 좁은 핀 간격은 점퍼선 보호캡을 벗겨 해결
  3. ✓8월 4주 · 16×16 LED 대신 P10 LED(32×16)로 교체, 전원 터미널로 포크 케이블 연결 후 점등 확인
  4. ✓9월 1주 · ✕/→ 모양이 깨지는 문제와 센서 핀 휨 발생 → 상위 모델 LD2450 구매
  5. ✓9월 2주 · LED 1~512번 점등으로 픽셀 배치 순서를 찾아 코드에 반영 → 원하는 ✕ / → 모양 출력
  6. ✓9월 3주 · LD2450 + ESP32: 사람의 거리(Y)·각도(X) 좌표 출력 확인 (최대 6 m · 수평 ±60° · 수직 ±35°), 보조배터리로 노트북 없이 동작
  7. ✓9월 4주 · 센서 ESP32 → LED ESP32 블루투스 연결(LED 쪽이 서버) — 전원만 있으면 사람 감지 시 우회전 금지 표시
  8. ✓10월 1주 · 사람이 사라진 뒤 1초 안전 지연 추가, 느슨한 점퍼선 고정 · 실내 시연 영상 (사람이 다가오면 빨간 ✕, 벗어나면 초록 →)
  9. ✓10월 2주 · 메타버스 시연 페이지(보문역 사거리)와 실제 LED USB 연동 모듈 제작 실기기 연결 시험 전
