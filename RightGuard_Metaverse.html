실제 장치와 연결하기

메타버스는 USB 케이블로 LED 유닛 ESP32와 대화합니다. 메타버스가 ‘우회전 불가’로 판단하면 실제 LED가 ✕로 바뀌고, 현실 레이더가 사람을 감지하면 메타버스에 그 사람이 나타납니다.

  1. LED 유닛 펌웨어에 RightGuardLink.h를 넣고 업로드합니다. (함께 전달한 파일 · 기존 코드에 4줄 추가)
  2. LED 유닛 ESP32를 노트북에 USB로 연결합니다. Arduino IDE의 시리얼 모니터는 꼭 닫아 주세요(포트를 한 프로그램만 쓸 수 있어요).
  3. 이 HTML 파일을 Chrome 또는 Edge에서 엽니다. Safari·Firefox는 USB 연결(Web Serial)을 지원하지 않아요. 미리보기 링크 안에서도 막혀 있으니 내려받은 파일로 여세요.
  4. ‘장치 연결 (USB)’을 누르고 ESP32 포트를 고릅니다. Mac: cu.usbserial-… / cu.SLAB_USBtoUART / cu.wchusbserial…
  5. 상태가 ‘연결됨’이 되면 ‘관제 모드’에서 보행자를 보내 보세요. 실제 LED가 같이 ✕ → →로 바뀝니다.

조절 패널 · ‘관제 모드’나 ‘직접 운전’에서 조절을 누르면 레이더 감지 거리·좌우 각도·조준 방향·설치 높이·기울기와 보행자 걷는 속도·키, 차량 속도·교통량을 바꿀 수 있어요. 측면도에서 설치를 높게 하면 기둥 가까운 아이가 빔 아래로 빠지는 것도 확인할 수 있어요. 자동 시연은 항상 기본값으로 재생됩니다.

Right Guard 판단 · 보행 신호가 초록이면 모퉁이에 있는 사람을 건너려는 사람으로 보고 ✕를 띄웁니다. 점멸·빨강일 때는 인도에서 기다리는 사람은 막지 않고(→), 횡단보도·차도 위에 있거나 차도로 뛰어드는 사람만 ✕예요. 메타버스는 신호 정보를 안다고 가정합니다(실제 장치는 신호기 연동이 필요). 보행자는 남은 신호 안에 다 건너지 못할 것 같으면 다음 신호를 기다립니다.

전시장 팁 · 관람객이 많아 실제 센서가 계속 반응하면 ‘장치 판단 방식’을 ‘메타버스만’으로 바꾸세요. 반대로 실제 사람으로 시연할 땐 ‘현실 센서만’을 고르면 메타버스는 결과만 보여 줍니다.
