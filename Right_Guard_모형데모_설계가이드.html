RIGHT GUARD

RIGHT TURN, RIGHT TIME · 창의연구 프로젝트 (CRP)
KOREA UNIVERSITY
KU CreativeX · 공감형 우회전 교통안전
실내 모형 교차로 데모 · 설계 가이드

중간평가용 “작동하는 실물”을 탁상 규모로 구현하는 방법. 보행자 감지 → 판단 → 도로 LED(STOP/SLOW)의 전체 루프를 보여주고, 그 위에서 감지율·오감지율·반응시간 데이터까지 뽑아내는 것이 목표예요.

0무엇을 보여줘야 하나
  • 보행자가 접근(INTENT)·횡단(WALKING)할 때 → LED STOP(적색), 없으면 SLOW(녹색) — 1초 이내
  • 낙엽·우산 같은 비보행자 물체는 걸러지는 것(오감지율 ≤ 5%)
  • 자문위원 지적 반영: 차량용 신호를 보행자가 오인하지 않도록 분리 설계
  • 위 동작을 반복 측정한 데이터 표로 증명 (7번 항목)

규모는 1:10~1:12 탁상 모형(약 60×60cm 보드)이면 충분. 실제 거리(150cm 등)는 모형에 맞춰 다시 잡습니다(6번).

1상단뷰 배치도
우회전 차량이 양보해야 하는 횡단보도를 S1(접근)·S2(횡단)로 감시하고, 결과를 운전자용 바닥 LED 화살표로 출력한다.
2재료 & 규모
  • 바닥판: 폼보드 60×60cm 1~2장
  • 도로/차선: 검정 절연테이프(아스팔트·차선), 흰색 테이프(횡단보도·정지선)
  • 차량: 미니카 1대(시야 기준). 보행자 프록시: 막대 끝 작은 원통/인형 또는 굴러오는 물체 — 접근→횡단 재현 가능해야 함
  • 비보행자 물체(오감지용): 작은 공·우산·나뭇잎
  • 센서 거치대: 미니 삼각대·블루택·케이블타이로 높이·각도 고정
3센서 배치 & 조준

S2 · 횡단 횡단보도 한쪽 끝에서 맞은편을 향해 → 횡단보도 위 거리 = WALKING.

S1 · 접근 같은 기둥에서 진입부(바깥)를 향하게 → 다가오는 보행자 = INTENT.

  • HC-SR04 빔 각도 약 15° — 바닥·벽 반사 피하게
  • 모형에선 거치 높이 5~10cm
  • 두 센서 간섭 시 코드에서 번갈아 측정
주의 · 일반 HC-SR04는 Echo가 5V라 라파(3.3V)에 바로 꽂으면 안 돼요 → 저항 분압(1k/2k) 또는 3.3V형 HC-SR04P 사용.
4LED 화살표 & 보행자 오인 방지 자문위원
  • 화살표는 차량 차로 바닥에 깔고 운전자 쪽으로만 보이게(눕히거나 차양)
  • 모양은 방향 화살표로(보행자 신호와 구분). STOP=적색 / SLOW=녹색
  • 페일세이프: 보행자 감지 시 무조건 STOP — 보행자가 착각해도 차량엔 STOP. 발표에서 명시
  • 여유 시 보행자측 보조 표시를 분리 색·위치로 추가
5차량 신호 모의 & 배선

신호등 상태(RED/GREEN)는 버튼/토글로 모의. 코드가 이 입력을 읽어 판단에 반영.

실제 시스템에선 신호등 연동/색 센서로 대체.

핀 맵 (컨트롤러 코드 기준)

  • 초음파: TRIG=23 ECHO=24
  • LED: RED=17 GREEN=27 (각 220~330Ω)
  • 신호 버튼: 22
  • WS2812B면 외부 5V + 데이터선 330Ω
6캘리브레이션 (모형에 맞춰 임계값 잡기)
  • 프록시를 횡단보도 위에 두고 거리 읽기 → D_WALK_CM
  • 프록시를 진입부 가장자리에 → D_ENTRY_CM
  • 평소 속도로 접근시키며 속도값 관찰 → V_INTENT_CMS
  • 신호가 깜빡이면 MEDIAN_N·LEAVE_FRAMES를 키워 안정화
  • 버튼→LED 전환 시간 측정 → 1초 이내 확인(latency_ms 로그)
팁 · --mock로 로직을 먼저 확정하면, 하드웨어에선 임계값 숫자만 바꾸면 됩니다.
7데모 시나리오 & 측정 프로토콜 중간평가 핵심

아래 시나리오를 각 20회 반복하고, 매 회 기대/실제 신호 · 반응시간을 기록(CSV 로그 사용).

#시나리오기대 신호측정 목적
①보행자 없음 (녹색)SLOW정상 통과 · 오감지 분모
②보행자 접근(진입부)STOPINTENT 감지율
③보행자 횡단 중STOPWALKING 감지율
④보행자 이탈STOP→SLOW클리어런스(안전 여유)
⑤비보행자 물체 이동(공·우산)SLOW 유지오감지율
⑥보행자 없음 + 적색STOP법규 분기 확인

산출: 감지율=②③ STOP 정확률 · 오감지율=①⑤ 오STOP 비율 · 반응시간=로그 latency 평균. 목표(95%/5%/1초)와 비교 표가 그대로 발표 자료.

8악천후·주야 프록시 테스트
  • 야간: 조명 끄고 LED 시인성 거리 측정(초음파는 빛 영향 거의 없음)
  • 비: 분무기로 센서 앞에 물 → 물방울 오감지 확인 → 필터/임계값 보완
  • 사각지대는 센서 각도 조정 또는 임계값 코드 수정
9중간평가 라이브 시연 순서 (약 3~4분)
  • ① 평상시(없음·녹색) → 녹색
  • ② 프록시 접근 → 즉시 적색(반응시간 강조)
  • ③ 횡단 유지 → 이탈 후 잠깐 STOP 유지되다 복귀(클리어런스)
  • ④ 공/우산 흔들기 → 녹색 유지(오감지 방지)
  • ⑤ 버튼으로 적색 → 보행자 없어도 STOP(법규)
  • ⑥ 마지막에 측정 데이터 표로 95%/5%/1초 달성도 제시
