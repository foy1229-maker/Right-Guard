우측통행 기준입니다. 우회전 차량은 중앙선 오른쪽 차선으로 진입하고, 차가 가로지르는 동쪽 횡단보도 양 끝(S1·S2)에 센서가 있습니다. 바닥 LED는 보행자에만 집중해요 — 한쪽에서라도 접근(INTENT)/횡단(WALKING)하면 적색(STOP), 없으면 녹색(SLOW). 차량은 보행자가 있으면 정지하고, 직진(교차로) 신호가 적색이면 일단 정지 후 보행자가 없을 때 서행 통과, 청신호면 곧바로 서행 우회전합니다.

    if ped in (WALKING, INTENT): return STOP
    return SLOW

작동 단계
1
차량 접근

우회전 차량이 우측 차선으로 접근해 정지선 앞에 섭니다. 횡단보도 안으로는 들어가지 않아요.

2
보행자 우선

S1(북측)·S2(우회전쪽) 중 하나라도 접근/횡단을 감지하면 LED 적색(STOP) → 신호와 무관하게 정지. 절대 먼저 못 나갑니다.

3
적신호(직진 X)

보행자가 없으면 일단 정지(일시정지) 후 → 주변 보행자가 없을 때 서행으로 우회전 통과.

4
청신호

보행자가 없으면 곧바로 서행(SLOW) 우회전. 보행자 이탈 시 약 1.5초 클리어런스 후 진행.
